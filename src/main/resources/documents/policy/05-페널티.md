# 페널티 정책

## 주문 거절 페널티
- 월간 주문 거절률 10% 초과 시 경고
- 20% 초과 시 검색 순위 하락 (7일간)
- 30% 초과 시 임시 영업 정지 (3일)

## 조리 지연 페널티
- 접수 후 예상 조리 시간 초과율 30% 이상: 경고
- 반복 시 검색 순위 하락

## 위생/안전 위반
- 고객 신고 접수 시 조사 진행
- 확인 시 즉시 영업 정지 + 개선 계획서 제출 필요
- 심각한 경우 퇴점 조치

## 리뷰 조작
- 자작 리뷰, 보상 조건 리뷰 유도 적발 시 즉시 경고
- 2회 적발 시 30일 영업 정지
- 3회 적발 시 강제 퇴점

## 페널티 해소
- 경고: 30일간 재발 없으면 자동 해소
- 영업 정지: 기간 경과 후 자동 복구
- 이의 신청: 사장님앱 > 고객센터에서 접수 (영업일 3일 내 회신)
