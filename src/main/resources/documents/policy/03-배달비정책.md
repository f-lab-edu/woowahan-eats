# 배달비 정책

## 플랫폼 배달 배달비
- 기본 배달비: 3,000원 (거리 3km 이내)
- 3km~5km: 3,500원
- 5km 이상: 4,000원~
- 우천/폭설 시 할증: +1,000원
- 심야 시간대(22시~06시) 할증: +1,000원

## 배달비 부담 주체
- 기본적으로 고객이 부담
- 매장에서 배달비 일부/전액 지원 가능 (프로모션)
- 플랫폼 쿠폰으로 배달비 할인 제공 시 플랫폼 부담

## 자체 배달
- 매장이 직접 설정 (최소 0원~)
- 자체 배달 시 플랫폼 배달비 없음
- 배달 관련 클레임은 매장 책임
