# 배달 설정

## 배달 방식
- **플랫폼 배달**: Woowahan Eats 소속 라이더가 배달 (배달비 별도)
- **자체 배달**: 매장 자체 배달 인력 활용 (배달비 매장 설정)

## 배달 지역 설정
- 매장 기준 반경 1km ~ 10km 범위 설정
- 지역별 배달비 차등 설정 가능
- 원거리 배달 시 추가 배달비 설정 가능

## 예상 배달 시간
- 조리 시간 + 배달 시간으로 자동 계산
- 조리 시간은 매장에서 설정 (기본 20분)
- 피크 시간대 자동 조정 기능 제공

## 배달 현황 확인
- 사장님앱에서 실시간 배달 상태 확인
- 라이더 배정, 픽업, 배달중, 완료 단계별 알림
